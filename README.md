# ChatGPT Prompt Queue

ChatGPT 网页版**排队发送**（prompt queue / queued messages）：提前排好后面几轮要发的消息，上一轮回复完整生成完、停稳 2 秒后，自动发下一条。

和 Claude Code、Cursor 的 queued messages 是同一类功能；区别是这里严格等整轮回复结束才发下一条，不会插进正在进行的那一轮（那种叫 steer）。

## 安装（Chrome，一次性）

1. 地址栏打开 `chrome://extensions`，右上角打开「开发者模式」。
2. 点「加载已解压的扩展程序」，选这个文件夹 `~/Documents/chatgpt-queue`（文件框里按 ⌘⇧G 粘贴路径）。
3. 已打开的 ChatGPT 标签刷新一下。

改了 `content.js` 后，在 `chrome://extensions` 里点这个扩展的刷新图标，再刷新 ChatGPT 页面。

## 用法

- **生成中按 Enter** → 输入框内容进队列（ChatGPT 原本这时按 Enter 没反应）。
- **任何时候按 ⌥Enter** → 进队列。
- 队列里还有没发完的（且没暂停）时，普通 Enter 也进队列，保证顺序不乱。
- 右下角面板：看队列、↑ 调顺序、✎ 改、✕ 删、⏸ 暂停 / ▶ 继续、清空；双击一条展开全文。
- 自动发送时如果你输入框里正打着草稿，会先收起来，发完放回去。
- **对话栏加宽**：ChatGPT 默认把对话和输入框限在约 808px，两边大片留白；扩展把它放宽到「窗口内容区宽度减 64px，最多 1600px」。
- **每个对话一份队列**：切到哪个对话，面板就显示哪个对话的队列、暂停和报错状态，不会发错地方。在首页 / 新对话里攒的队列，第一条发出去、地址换成真对话 id 后自动跟过去。
- 队列存在这个标签页的 sessionStorage 里，刷新不丢，关标签就没了。队列空了，暂停和报错提示自动清掉。
- 发送失败（按钮不可用、点了没发出去，比如额度用完）会自动暂停并提示。
- 对话里出现红色出错条（Unknown error、网络错误、对话太长等），或上一条发出去没收到回复，也会自动暂停，面板顶上写明原因；那条没收到回复的消息放回队首，前面标 ⚠。看过之后点 ▶ 继续，会从队首那条重新发。

## 实测记下的坑（26-11-01）

- 页面已经没有 `data-testid`；生成中的判据是输入框所在 form 里出现 aria-label「停止 / Stop」的按钮。
- 刚按发送、停止键还没出来的那一两秒里再按 Enter，ChatGPT 会把前一条吞掉只留后一条，所以发送后 8 秒内（直到停止键出现）都算「在生成」。
- 新对话第一条发出后地址先是 `/c/local-chatgpt:xxx`，过几秒才换成真 id；临时 id 不当作对话 id。
- 往输入框（ProseMirror）塞文字用模拟粘贴事件，多行能保留。
- 新对话换真 id 时输入框会被重建，按键判断要看「目标在不在输入框里」，不能跟当前输入框节点比（0.1.1 修，之前 ⌥Enter 漏过一次）。
- 在侧栏切对话时，旧对话整块 `<main>`（连输入框）可能还留在页面里没拆掉，宽高为 0，页面上同时有两个输入框、两份对话内容；输入框只认看得见的那个，判断最后一轮和出错条只看输入框所在的那块 `<main>`（0.2.0 修，之前往藏着的输入框里塞过字）。
- 对话栏宽度由 `--thread-content-max-width` 变量控制，写在 Tailwind 任意属性类 `[--thread-content-max-width:var(--thread-content-responsive-max-width,inherit)]` 里；在 `:root` 上改 `--thread-content-expanded-max-width` 不生效，要在带这个类的元素上直接改变量（0.3.0）。
- 发出去立刻报错（Unknown error）时根本不出停止键，光看「停止键消失」会当成回复完了，2 秒后接着发下一条。11-01 夜里一个 80 多轮、30 多万字的长对话就这样连丢最后 3 条（发送接口 `POST /backend-api/f/conversation` 回 **413**，就是对话太长到顶了，出错条只给「开始新聊天」按钮；同一对话重试照样 413）。0.1.3 起发下一条前多查两件事：最后一轮之后有没有 `main [role=alert]` 出错条；最后一轮是不是用户自己的话（每轮开头有读屏用的隐藏 `h4`「你说：」/「ChatGPT 说：」）。

本机另有 `dev-serve.py`（想用本地 HTTP 往页面注入代码，被 chatgpt.com 的 CSP 拦了，没用上）和 `data/`（导出的对话），都不入库。
